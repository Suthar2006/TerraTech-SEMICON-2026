FINAL LOCALIZATION ALGORITHM

1. INPUT
Each test pair contains a reference image and a larger search image.

2. LOCALIZATION
The final localization algorithm is the validated algorithm used in
localization_FINAL_FAST.py. The FAST version distributes independent pair
processing across CPU worker processes while keeping the localization
algorithm unchanged.

3. RECOVERY
The model contains recovery logic used for difficult or ambiguous cases.
During final validation, recovery was used on 223 cases.

4. AMBIGUITY HANDLING
Ambiguous cases are tracked separately. The final validation recorded
47 ambiguous cases.

5. PARALLEL EXECUTION
FAST mode uses multiple CPU workers to process independent image pairs.
The validated run used 6 workers on a system reporting 12 CPU threads.
Parallel execution changes processing distribution, not the localization
decision logic.

6. OUTPUT
The model produces localization results in CSV form and stores failed-case
diagnostic material for analysis.

IMPORTANT
The final submission uses localization_FINAL_FAST.py as the frozen final
model. Experimental Day 11 V2-V5 recovery strategies are not part of the
final validated algorithm.
